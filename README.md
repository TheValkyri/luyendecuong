# Ứng Dụng Ôn Luyện Tiếng Anh 11 — THPT Vĩnh Thuận (Giữa HK1)

Ứng dụng web trắc nghiệm & tự luận ôn thi giữa học kỳ I môn Tiếng Anh lớp 11 (Chương trình Global Success) dành cho học sinh trường THPT Vĩnh Thuận - An Giang.

## Tính năng nổi bật
- **Đầy đủ 89 câu hỏi:** Điền từ (Cloze Test), Đọc hiểu (Reading), Sắp xếp trật tự câu (Sentence Order), Viết lại câu (Writing).
- **Đáp án chuẩn giáo viên 100%:** Trích xuất từ đề cương gốc của trường.
- **Giao diện Anti-Slop:** Thiết kế tối giản chuẩn Editorial / Swiss Typography, 100% vector icons sắc nét.
- **Hỗ trợ 3 giao diện:** Dark Obsidian, Editorial Paper, Eye-Care Sepia.
- **Hệ thống ghép câu thông minh (Sentence Order Live Assembler):** Tự động ghép văn bản hoàn chỉnh để kiểm tra độ mạch lạc trước khi chốt đáp án.
- **Cửa sổ đọc bài khóa nổi (Passage Sheet Drawer):** Đọc bài khóa không cần cuộn ngược trên điện thoại.
- **Tự động lưu tiến độ (Crash-proof Autosave):** Lưu câu trả lời liên tục vào localStorage.
- **Trang Quản trị (Admin Dashboard):** Bảng xếp hạng, điểm số học sinh, xem chi tiết từng bài làm và xuất file Excel CSV.
